# Data Dictionary: Status Cue Salience

Originally generated by `scripts/diagnostics/collect_status_cue_salience_sources.py`; focal SAU/GAB correction uses `scripts/diagnostics/correct_status_cue_sau_gab.py` (2026-09-22 UTC). The original collector is frozen after correction, because its old sample onsets and overwrite behavior are unsuitable for new runs.

**Scope of the focal correction:** `entry_year` in the three legacy CSVs is now the M2 goods-export onset for SAU (2013) and GAB (2017); the other 12 countries retain their original values and coding. Use `status_cue_sau_gab_windows.csv` to distinguish M2 and M3, including GAB M3 onset 2015. This is not a global harmonization of the legacy sample. `mentions_china_rank_change` retains its historical meaning of a statement that China became **or is** first, not necessarily the announcement of a transition. The GAB 2016 source is preserved with `DO_NOT_COUNT: M3_WINDOW_ONLY` in the legacy M2 counters but counts in its explicitly separate M3 window table.

## status_cue_sau_gab_source_audit.csv

One row per new candidate document; source ids link to `SOURCES.yaml` and the versioned collection manifest. Failed access is retained. A newspaper reporting official statistics is counted once as news, not again as official uptake.

| Variable | Type | Description | Source (id) | Unit / valid values |
|---|---|---|---|---|
| source_id | string | Stable candidate identifier; joins to source manifest. | SOURCES.yaml | unique document |
| iso3c | string | Audited country. | manifest | SAU, GAB |
| publication_date | date | Candidate's publication date; full-raw verification is separate. | source metadata | YYYY-MM-DD |
| metric_window | string | Target publication window, not a claim of metric equivalence. | manifest | M2, M3, M2_M3 |
| source_channel | string | Distinguishes newspaper, local digital news, public agency, and newspaper republishing agency material. | source_id | newspaper, local_digital_news, national_public_news_agency, newspaper_republishing_national_news_agency |
| metric_scope | string | Actual metric/direction of the candidate's rank. | source_id | goods_exports, exports_unspecified_services, two_way_trade, reversed_partner_total_trade |
| eligible_publication | boolean | Candidate has positive top-China cue content in the intended publication window before raw verification; false for contrary or reversed rank. | manual coding | true/false |
| full_raw_verified | boolean | Full archived response contains required date/content markers; PDF additionally inspected visually. Not equivalent to positive cue eligibility. | raw document | true/false |
| counted_in_window | boolean | Positive candidate and full raw/date verified, counted in its named window only. M3-window cue may lack strict M3 metric alignment. | derived | true/false |
| fetch_status | string | Final access result; ok alone does not prove article-text recovery. | fetch_results.json | ok, http_error, network_error, access_challenge_stop, disallowed_stop, robots_unavailable_stop |
| robots_status | string | Robots decision before automated page fetch. | robots_results.json | allowed, no_robots_file, disallowed_stop, robots_unavailable_stop |
| raw_file | string | Preserved response path; blank when source fetch was stopped before request. | fetch_results.json | repo-relative path or blank |
| sha256 | string | SHA-256 of archived response, not its text extraction. | raw document | 64 hexadecimal characters or blank |
| url | string | Original candidate source URL. | source_id | URL |
| accessed_at | datetime | UTC timestamp for collection run; reused successful raws retain original timestamp. | fetch_results.json | ISO-8601 |

The original `status_cue_source_evidence.csv` also includes these candidates with its unchanged column schema. `raw_file` for SPA is a preserved HTML shell; `full_raw_verified=false` prevents treating it as full article evidence. All positive cues require full preserved text. `excerpt_under_25_words` remains a short original-language verification excerpt, not a reconstructed full passage.

## Reproduction and provenance

Run `python3 scripts/diagnostics/correct_status_cue_sau_gab.py --build --run-dir data/raw/status_cue_salience/focused_sau_gab/20260922T025500Z` to reconstruct the focal processed files without network. Run `Rscript scripts/diagnostics/analyze_status_cue_salience_event_study.R --appendix-only` to rebuild the appendix. The focal Python script uses the standard library and the existing `pdftotext` command; collection can use macOS curl's normal verified certificate store when Python lacks a CA issuer. No credentials or additional packages are required for the Python workflow.

For new collection, choose a new run directory with `--collect`. Each run preserves `manifest.json`, per-source metadata, `fetch_results.json`, and `robots_results.json`; `--reuse-successful-from` reuses only hash-verified successful raw files. All raw responses, including failures and robots, are covered by `data/raw/status_cue_salience/checksums.sha256`. Access and license limitations are in the focused collection report; no publisher granted a redistribution license in this audit.

Mechanical verification is reproducible with `python3 scripts/diagnostics/correct_status_cue_sau_gab.py --validate --baseline-ref 05ffb40`, which compares the three legacy CSVs outside SAU/GAB, all 89 preexisting raw-file hashes, and the two unchanged numerical outputs against the pre-correction commit. It also checks unique ids, required fields, date windows, positive-source validation, source excerpts and all current checksums. Results are saved in `quality_reports/status_cue_salience/sau_gab_integrity_checks.json`. Python syntax, YAML parsing/id uniqueness, R appendix generation and `git diff --check` also passed; R reported package-build-version warnings without errors.
