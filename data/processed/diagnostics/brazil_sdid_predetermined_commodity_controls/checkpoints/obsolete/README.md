# Checkpoints obsoletos

Esta pasta preserva checkpoints que não pertencem ao snapshot inferencial ativo.

`placebo_se_existing_commodity_gfc_exposure_1000_pre_contract.rds` foi criado antes do contrato de fingerprints SHA256 completo. Ele reproduz uma versão legada da exposição a commodities contaminada por fluxos domésticos e produz erro-padrão divergente do alvo auditado. O arquivo é mantido apenas para rastreabilidade histórica e não é lido, manifestado nem usado na inferência válida.
